# The Word You'd Delete From the Dictionary

Entry for the make.fun bounty
`u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2`.

## The word

**impossible**

## Why

Delete "impossible" from the dictionary and nothing is impossible any
more. The joke is instant — it needs no explanation — and it comes
entirely from the word itself: erase the word for "cannot be done"
and suddenly everything can be done.

## How it runs

`main.py` (Python 3, standard library only, no network, no randomness)
writes exactly that one word, with no trailing newline, to
`/output/entry.txt` (10 bytes, within the 1–77 character gate).

Run it:

```sh
python3 main.py
```
